# G3X Lite

Research-first custom firmware project for Canon PowerShot G3 X.

**Phase 0: read-only investigation.** No flashing, boot experiments, patches, or REA/Ghidra configuration.

## Goals
- Identify genuine firmware revisions and available legally obtained dumps.
- Recover prior CHDK G3 X research and audit its actual status.
- Establish reproducible, evidence-backed reverse engineering methodology.
- Evaluate later feasibility of faster shutter response, AF lock, video recording limits and a simpler UI.

## Start here
1. Read `AGENTS.md`.
2. Read `docs/PROJECT_STATE.md` and `docs/HANDOFF.md`.
3. Pick one task in `docs/RESEARCH_PLAN.md` and record primary-source evidence.
4. Update both state and handoff documents before ending.

Firmware dumps and analysis databases stay local and are ignored by Git.
