## Closest Sibling Rationale

PowerShot G5 X (`chdk-port/platform/g5x`) is the closest sibling to GM1.10C for the short-press mechanism:
1. **Ineffectiveness of `0x4FFC` Reboot Flag**: Sibling ports `g7x` (`loader/g7x/main.c:39`) and `sx60hs` (`loader/sx60hs/main.c:17`) bypass shutdown by writing soft-reboot flag `*(volatile unsigned *)(0x4ffc) = 0x12345678`. On G3 X, `0x4FFC` does not prevent shutdown (`docs/PORT5B_HISTORICAL_BOOT_COMPARISON.md:115`, `docs/PORT6A_POWERON_EVIDENCE.md:36,108`; historical `g3x_110e.patch:P1681-1717`).
2. **Direct Power-Cut Supervision Bypass**: G5 X loader (`chdk-port/loader/g5x/main.c:1-49`) similarly omits `0x4FFC`. Instead, G5 X intercepts the startup check in `boot.c` (`sub_fc0ecf20_my:411-420`), commenting out the shutdown branch and returning `movs r0, #1`. G3 X GM1.10C ROM uses the exact same supervisory structure in `sub_fc05b962` and `sub_fc1284ac`.
3. **Startup Mode Discrimination**: G5 X reads the Power GPIO in `boot.c:168-183` (`sub_fc066258_my`) to write the start mode word (`0x100000` Rec / `0x200000` Play). G3 X GM1.10C preserves the start cause in low RAM `*(0x9BC4 + 12)` (`0x00009BD0`) where `0x00080000` is Power and `0x00100000` is Playback.
4. **Architecture & OS**: Both cameras share DIGIC 6 (Cortex-A9), DryOS 57, and identical `task_PhySw` stack enlargement requirements (`0x2000` B via `j_CreateTaskStrictly`).

## Power Key Bit Verification & Source Comparison

- **`reference/finsig_gm110c/physw_bits.txt:18`**: Address `0xFC66C9C0`, info `0x01010211`, event `0x00000100` (PressPowerButton), index `0` (word 0), bit `0x00020000` (bit 17), non-inverted: 1.
- **`docs/PORT46_KEYMAP.md:28, 31, 176`**: `KEY_POWER` mapped to word 0, bit 17 (`0x00020000`), event `0x100`. Confirms `KEY_POWER` is intentionally excluded from `KEYS_MASK0` (`0x000533F9`) so normal power-off is never swallowed.
- **Disagreement Assessment**: **ZERO disagreement**. Both sources agree that the Power button bit is `physw_status[0]` bit 17 (`0x00020000`).
- **Contrast with Playback Key**: Playback button is word 0, bit 16 (`0x00010000`, event `0x101`). `KEYS_MASK0 = 0x000533F9` includes bit 16 (allowing CHDK ALT suppression) while strictly excluding bit 17 (`docs/PORT7B_PLAYBACK_MASK_CORRECTION.md:5,48-57`, `docs/PORT9B_RUNTIME_CONTRACT.md:36`).
