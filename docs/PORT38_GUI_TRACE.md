## Build Plan (GUI4)
1. Provide a dedicated G3X GUI4 font driver in `libplatformsub_candidate.a` (implementing `rbf_draw_char`, `rbf_char_width`, `rbf_font_height`, `rbf_str_width`, `rbf_draw_string_len`, `rbf_draw_menu_header`, etc.) with native 16x32 glyph rendering, character advance 16 px, and row pitch 32 px, completely eliminating ld `--wrap` font dependencies.
2. In `gui_candidate.c` (`g3x_gui_kbd_redraw`) and `rbf_draw_menu_header`, paint the full opaque bounding rectangle (`x = 10..889`, `y = 12..587`, width 880, height 576, `COLOR_BLACK`, opacity 255 directly into `opacity_buffer[active_bitmap_buffer & 1]`), ensuring the fill and paint rectangles are identical and occluding all photo show-through strips.
3. In `conf_candidate.c` (`conf_restore`), configure contrasting title bar colors (`conf.menu_title_color.bg.col = 1` for `COLOR_BLACK`, `conf.menu_title_color.fg.col = 2` for `COLOR_WHITE`), ensuring a solid dark header with legible white text.
4. Keep the PORT-37 zero-flicker behaviour (no periodic `force_redraw`) and preserved Step 8/9 code paths (sentinel recovery on stock UI overwrite and clean ALT exit).
