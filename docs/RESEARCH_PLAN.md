# Phase 0 research plan

## R01 — CHDK archaeology
Find original G3 X port thread, author posts, patches, forks, binaries, supported revisions, last verified status. Preserve exact links and hashes when available. Do not mistake booting a logo for a stable port.

## R02 — Firmware inventory
Document Canon official firmware revisions and release notes; independently verify firmware dump provenance, format, size and hash. Do not download or redistribute proprietary dumps without authorization.

## R03 — Architecture and boot
Confirm DIGIC generation, CPU instruction sets, ROM/RAM mapping and loader mechanism from original technical evidence. Mark unresolved facts explicitly.

## R04 — Capability baseline
Record documented AF lock, MF, continuous shooting, recording time limits and existing Canon UI behavior. Distinguish single-shot shutter lag from burst FPS.

## R05 — REA feasibility (documentation only)
Compare REA native/firmware support and macOS requirements; identify any Linux-only extraction tools. Do not install or configure tools yet.

## Exit criteria
Primary-source report, firmware revision matrix, reproducible next-phase analysis plan, risk register, and explicit owner approval to enter Phase 1.
