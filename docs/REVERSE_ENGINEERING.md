# Reverse engineering methodology (future phase)

1. Establish provenance and SHA-256 of legally acquired input.
2. Identify containers/segments without executing content.
3. Validate architecture and load addresses against independent evidence.
4. Create reproducible disassembly/decompilation projects.
5. Annotate functions and offsets with confidence and citations.
6. Plan non-invasive tests before considering hardware execution.

**Not authorized in Phase 0:** REA/Ghidra installation or setup, binary patches, firmware flashing, camera tests.
