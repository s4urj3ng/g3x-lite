## Notes

1. **Navigation key cross-check**: `KEY_UP` (w0.b5, `0x20`), `KEY_DOWN` (w0.b6, `0x40`), `KEY_LEFT` (w0.b8, `0x100`), `KEY_RIGHT` (w0.b7, `0x80`), `KEY_SET` (w0.b9, `0x200`), and `KEY_MENU` (w0.b4, `0x10`) match `reference/finsig_gm110c/physw_bits.txt:7-12` and `docs/PORT46_KEYMAP.md:17-22` 100% with zero mismatches. All are covered by `KEYS_MASK0 = 0x000533F9`. Historical zoom candidate mismatch (GM1.10C events 0x16/0x12 vs CHDK 0x04/0x03 in `PORT46_KEYMAP.md:40`) does not affect menu navigation.
2. **In-session persistence & save skip**: Item edits directly mutate the `conf` struct in RAM (`chdk-port/core/conf.c:20`). Values persist across menu close and re-open within session without card writes. Under `G3X_GUI_MENU=1` and `G3X_DISABLE_CARD_WRITES=1` / `OPT_DISABLE_FILE_WRITES=1`, `conf_save()` entry is intercepted at `core/conf.c:1159`, calls `g3x_conf_record_save_result(3)` (`G3X_CONF_SAVE_OFF`), and immediately returns, safely displaying `"SAVE:OFF"` on the OSD banner (`gui_diag.h:975,1317`).
3. **Playback mode & FINSIG stubs**: In playback mode, `playrec_mode` (`0x0000C4D4`) evaluates to 0 or 1, causing `rec_mode_active()` to return 0 and `mode_get()` to assign `camera_info.state.mode_play = 1`, `mode_rec = 0`. Neither ALT mode entry nor the menu keyboard handler is gated off in playback mode. No missing FINSIG stubs are required. For build task auditing, an optional bounded ROM read `0xFC09BD50..0xFC09BD8F` (64 bytes) can verify `simple_movie_status` reference in `task_MovieRecord` around `0xFC09BD60`.
4. **PORT-51 RESTORE2 integration**: Item edits set `gui_menu_redraw = 1`, updating the modified row in the DBUF shadow layer (`g3x_shadow_bitmap`/`opacity`) and marking the dirty rectangle. The PORT-51 RESTORE2 synchronous epilogue hook (`g3x_shadow2_blit_restore_target` at `0xFC380675`) blits the dirty rectangle to BOTH `bitmap_buffer[0..1]` and `opacity_buffer[0..1]` on every display flip, guaranteeing that in-session edits are rendered without tear or flicker.
