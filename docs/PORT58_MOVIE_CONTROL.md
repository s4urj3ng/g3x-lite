## 2. PORT-57 Continuation State Machine, Volatile Menu Gating & Status Representations

### 2.1 PORT-57 Actual Continuation States & Fault/Cancellation Behavior

In `chdk-port/platform/g3x/movie_status.h:107-128` and `chdk-port/platform/g3x/sub/110c/movie_rec.c:216-754`, PORT-57 defines one state machine (`g3x_autocont_state`) polled every `10 ms` inside `mykbd_task`:

1. **`G3X_AUTOCONT_DISARMED` (`0`, `"OFF"`)**:
   - Default boot state (`movie_rec.c:242`). No synthetic `KEY_VIDEO` ownership (`g3x_autocont_synth_owned == 0`).
   - Latches `g3x_autocont_saw_boot_idle = 1` only after observing `mr_rec_state == 0` (`G3X_MOVIE_STATE_IDLE`, `movie_rec.c:492-495`).
   - Clears `g3x_autocont_cancel_latched = 0` only when `mr_rec_state == 0` and physical `KEY_VIDEO` is released (`!phys_video_pressed`, `movie_rec.c:502-508`).
   - Arms (`-> G3X_AUTOCONT_RECORDING`) only when `prev_state == 0 && cur_state == 1`, `!g3x_autocont_cancel_latched`, and `(!phys_video_pressed || g3x_autocont_idle_start_press_seen)` (`movie_rec.c:510-524`).
2. **`G3X_AUTOCONT_RECORDING` (`1`, `"ARM"`)**:
   - Tracks `g3x_autocont_update_active_metrics()` (`movie_rec.c:302-327`): latches `saw_frames_in_bounds = 1` when `cur_frames < max_frames` (after `cur_frames` changes from prior stop snapshot) and `saw_size_in_bounds = 1` when `proj_total <= size_cap && avail_space >= proj_total` (after `stream_bytes` or `proj_total` changes from prior stop snapshot).
   - **Initial start-press carry-over**: Bounded to `G3X_AUTOCONT_START_HOLD_POLLS = 50` (`500 ms`, `movie_rec.c:520-521,547-567`). Once physical `KEY_VIDEO` is released during `RECORDING`, `start_hold_remaining` drops to `0`; any subsequent physical `KEY_VIDEO` press (`phys_video_pressed == 1`) or holding past `50` polls immediately triggers `g3x_autocont_disarm(1)` (terminal user cancellation).
   - **Stop attribution (`1 -> != 1`)**: If `phys_video_pressed == 1`, immediately calls `g3x_autocont_disarm(1)` (`movie_rec.c:558-561`). Otherwise calls `g3x_autocont_is_eligible_auto_stop()` (`movie_rec.c:329-412,573-594`), which returns `1` only for Reason 4 (`mr_stop_reason == 4 && saw_frames_in_bounds && cur_frames >= max_frames`) or Reason 3 (`mr_stop_reason == 3 && saw_size_in_bounds && avail_space >= proj_total && proj_total > size_cap`). Any other stop reason (`0`, `1`, `2`, `>= 5`, card full, or stale `3`/`4` without counter movement) calls `g3x_autocont_disarm(0)`.
   - On an eligible auto-stop: transitions to `G3X_AUTOCONT_SETTLE` (if `cur_state == 0`) or `G3X_AUTOCONT_WAIT_IDLE` (if `cur_state` in `2..4`).
3. **`G3X_AUTOCONT_WAIT_IDLE` (`2`, `"WAIT"`)**:
   - Waits up to `G3X_AUTOCONT_WAIT_IDLE_MAX_POLLS = 500` (`5.0 s`) for `mr_rec_state` in `2..4` to reach `0` (`movie_rec.c:598-623`).
   - Disarms on `phys_video_pressed` (`g3x_autocont_disarm(1)`), unexpected `cur_state == 1` (`g3x_autocont_disarm(0)`), or timeout (`timer == 0 -> g3x_autocont_disarm(0)`).
4. **`G3X_AUTOCONT_SETTLE` (`3`, `"SETL"`)**:
   - Requires `G3X_AUTOCONT_SETTLE_POLLS = 50` (`500 ms`) of continuous `mr_rec_state == 0` (`movie_rec.c:626-651`).
   - Disarms on `phys_video_pressed` (`g3x_autocont_disarm(1)`) or any non-idle bounce `cur_state != 0` (`g3x_autocont_disarm(0)`).
   - On completion (`timer == 0`), transitions to `G3X_AUTOCONT_PRESSING` and calls `g3x_autocont_assert_synth_press()`.
5. **`G3X_AUTOCONT_PRESSING` (`4`, `"PRS"`)**:
   - Asserts synthetic `KEY_VIDEO` for `G3X_AUTOCONT_PRESS_POLLS = 6` (`60 ms`, `movie_rec.c:653-678`) via `g3x_autocont_assert_synth_press()` (`g3x_autocont_synth_owned = 1`, `kbd_key_press(KEY_VIDEO)`, `physw_status[0] &= ~0x00000008`).
   - Disarms immediately on `phys_video_pressed` (`g3x_autocont_disarm(1)`) or unexpected state outside `{0, 1}` (`g3x_autocont_disarm(0)`).
   - On completion (`timer == 0`), calls `g3x_autocont_release_synth_input()` and transitions to `G3X_AUTOCONT_RELEASING`.
6. **`G3X_AUTOCONT_RELEASING` (`5`, `"REL"`)**:
   - Waits `G3X_AUTOCONT_RELEASE_POLLS = 6` (`60 ms`, `movie_rec.c:680-713`).
   - Disarms immediately on `phys_video_pressed` (`g3x_autocont_disarm(1)`) or unexpected state outside `{0, 1}` (`g3x_autocont_disarm(0)`).
   - If `cur_state == 1` is seen on the final release poll (`timer == 0`), increments `g3x_autocont_restart_count` and transitions directly to `G3X_AUTOCONT_RECORDING`; if `cur_state == 0`, transitions to `G3X_AUTOCONT_WAIT_CONFIRM` (`200` polls = `2.0 s`).
7. **`G3X_AUTOCONT_WAIT_CONFIRM` (`6`, `"CONF"`)**:
   - Waits up to `G3X_AUTOCONT_CONFIRM_MAX_POLLS = 200` (`2.0 s`, `movie_rec.c:716-745`) for `mr_rec_state == 1`.
   - When `cur_state == 1` arrives, increments `g3x_autocont_restart_count` and enters `G3X_AUTOCONT_RECORDING`.
   - Disarms on `phys_video_pressed` (`g3x_autocont_disarm(1)`), non-idle/non-recording state (`cur_state != 0 -> g3x_autocont_disarm(0)`), or timeout (`timer == 0 -> g3x_autocont_disarm(0)`).

### 2.2 Volatile Menu Toggle Rules (Enable at Confirmed Idle, Arm on Deliberate Start, Disable Without Stopping Clip)

Adding user control requires only a volatile enable flag (`static int g3x_autocont_enabled = 0;`) and a volatile last-disarm reason (`static int g3x_autocont_disarm_reason = 0;`, e.g. `0 = NONE`, `1 = USER_CANCEL`, `2 = FAULT_OR_TIMEOUT`) inside `chdk-port/platform/g3x/sub/110c/movie_rec.c`:

1. **Confirmed-Idle Enable Gating (`0 -> 1`)**:
   - A predicate `g3x_movie_autocont_can_enable(void)` checks:
     1. `camera_info.state.mode_play == 0` (camera is in shooting/live-view mode, not playback; `movie_rec.c:478`),
     2. `g3x_get_movie_status() == G3X_MOVIE_STATE_IDLE` (`mr_rec_state == 0` at `0x0000C0C8`; `movie_rec.c:22-33`),
     3. `g3x_autocont_saw_boot_idle != 0` (or `g3x_get_movie_status() == 0` confirmed with no unknown/in-progress state; `movie_rec.c:248,492-495`), and
     4. `((unsigned int)kbd_new_state[0] & G3X_KEY_VIDEO_BIT) != 0U` (raw physical `KEY_VIDEO` is currently released; `movie_rec.c:475`).
   - When the user attempts to enable the menu toggle (`g3x_movie_autocont_set_enabled(1)`):
     - If `g3x_movie_autocont_can_enable()` is **false** (e.g., `mr_rec_state == 1` recording, `mr_rec_state` in `2..4` stopping, `mr_rec_state` out-of-range, `mode_play != 0`, or physical `KEY_VIDEO` held), the enable request is **refused**: `g3x_autocont_enabled` remains `0`, `g3x_autocont_state` remains `G3X_AUTOCONT_DISARMED`, and the menu item value remains `0` (`Off`).
     - If `g3x_movie_autocont_can_enable()` is **true**, `g3x_autocont_enabled` becomes `1`, `g3x_autocont_disarm_reason` is cleared to `0`, `g3x_autocont_cancel_latched` is `0`, `g3x_autocont_idle_start_press_seen` is reset to `0`, `g3x_autocont_prev_rec_state` is set to `G3X_MOVIE_STATE_IDLE (0)`, and `g3x_autocont_state` remains `G3X_AUTOCONT_DISARMED (0)` (**Enabled but Unarmed**).
2. **Deliberate-Start Arming (`Enabled but Unarmed -> Armed`)**:
   - In `g3x_movie_autocont_poll()` (`movie_rec.c:498-525`), the transition from `G3X_AUTOCONT_DISARMED` to `G3X_AUTOCONT_RECORDING` is gated on `g3x_autocont_enabled != 0`.
   - Because enabling is only accepted at confirmed `IDLE (0)` with `g3x_autocont_prev_rec_state = 0` and `g3x_autocont_idle_start_press_seen = 0`, the state machine cannot arm on an already-running clip. It transitions to `G3X_AUTOCONT_RECORDING` (**Armed**) **only** after a subsequent deliberate physical recording start (`prev_state == 0 && cur_state == 1` with `!g3x_autocont_cancel_latched && (!phys_video_pressed || g3x_autocont_idle_start_press_seen)`).
3. **Disabling Continuation Without Stopping an Active Clip (`1 -> 0`)**:
   - Calling `g3x_movie_autocont_set_enabled(0)` is **always accepted in every state** (including while `mr_rec_state == 1` recording or during `WAIT_IDLE`, `SETTLE`, `PRESSING`, `RELEASING`, or `WAIT_CONFIRM`).
   - On `1 -> 0`:
     1. Sets `g3x_autocont_enabled = 0` and `g3x_autocont_disarm_reason = 0`.
     2. Calls `g3x_autocont_disarm(0)` (`movie_rec.c:414-423`), which invokes `g3x_autocont_release_synth_input()` (`movie_rec.c:286-297`), resets timers and active-clip bounds flags, and sets `g3x_autocont_state = G3X_AUTOCONT_DISARMED`.
     3. **Never** calls `kbd_key_press(KEY_VIDEO)` and **never** writes to `MovieRecorder` RAM (`0x0000C078..0x0000C2AF`). If a clip is currently recording (`mr_rec_state == 1`), Canon firmware continues recording that clip uninterrupted until its natural stock limit or a physical Movie button press.
4. **Terminal Physical-Stop Precedence & Continuation-Owned Synthetic-Key Release**:
   - Raw physical `KEY_VIDEO` (`((unsigned int)kbd_new_state[0] & 0x00000008U) == 0U`) is sampled before any state transition (`movie_rec.c:475`).
   - Any physical `KEY_VIDEO` press after the initial start-press release in `G3X_AUTOCONT_RECORDING`, on a `1 -> != 1` transition, or during `WAIT_IDLE`, `SETTLE`, `PRESSING`, `RELEASING`, or `WAIT_CONFIRM` immediately calls `g3x_autocont_disarm(1)`, setting `g3x_autocont_state = G3X_AUTOCONT_DISARMED`, `g3x_autocont_cancel_latched = 1`, and recording `g3x_autocont_disarm_reason = 1` (user cancel) while auto-disarming continuation.
