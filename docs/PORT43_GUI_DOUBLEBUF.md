# PORT-43: Double-Buffered Overlay, Fast Fills, Partial Redraw, and Shadow Restore

This document records the implementation of `G3X_GUI_DBUF=1` (opt-in compile-time switch for PowerShot G3 X GM1.10C) designed to eliminate the overlay flicker observed in the PORT-42 owner trial (menu repainting as black bands growing down over 5-8 frames, followed by disappearance to live view).

All changes are gated behind `#if defined(G3X_GUI_DBUF) && (G3X_GUI_DBUF == 1)`. When the switch is disabled, all builds produce 100% byte-identical outputs to their existing manifests.

### Full Repaint Triggers

Full menu clear and repaint (`gui_menu_redraw = 2`, invoking `g3x_fill_menu_opaque_black()` and `gui_menu_draw_initial()`) is strictly limited to three explicit conditions:
1. **Menu open**: entering CHDK menu mode (`gui_menu_init`) sets `gui_menu_redraw = 2`, resets the shadow buffer, and clears the per-row cache.
2. **Submenu enter/exit**: opening a submenu (`gui_activate_sub_menu`) or navigating back to parent menu (`gui_menu_back`) triggers `gui_menu_erase_and_redraw` (`gui_menu_redraw = 2`).
3. **Sentinel loss unrecoverable by shadow blit**: stock UI overwrite detected by sentinel guard (`!draw_test_guard()`) where shadow is invalid or blit fails triggers `gui_redraw(1)` from `core/main.c`.

Navigation never does a full clear-and-repaint: cursor moves, value updates, and scroll-offset changes use partial redraw touching only changed rows/items with 32-bit fast fills. On scroll, visible row content changes are redrawn row-by-row while header, title, and frame remain completely untouched.
